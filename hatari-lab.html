Commandes clavier — Mac

Déplacements : flèches directionnelles.

Joystick FIRE : touche ` (accent grave). Maintenir pour tirer. La barre d'espace reste libre pour les jeux.

Touches de fonction : Fn + 1 à Fn + 0 pour F1 à F10, si macOS transmet ces touches au navigateur. Le réglage des touches de fonction dans macOS peut modifier leur comportement.

Clique une fois dans l'écran Atari avant de jouer. Plus besoin des boutons virtuels.

Pour tester : démarre un jeu depuis la disquette, puis essaie la croix et FIRE. Clique dans l'écran Atari pour lui donner le focus si nécessaire.
