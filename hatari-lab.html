Le testeur observe les événements sans les bloquer. Il affiche les codes reçus par le navigateur, pas un numéro de touche Atari universel : Hatari et les jeux peuvent ensuite interpréter certaines touches différemment.

Commandes clavier — Mac

Joystick : flèches directionnelles. Pour transmettre une flèche au clavier Atari plutôt qu’au joystick, maintiens Maj en même temps que la flèche (fonction native de Hatari).

Joystick FIRE : touche ` (accent grave). Maintenir pour tirer. La barre d'espace reste libre pour les jeux.

Touches de fonction : Fn + 1 à Fn + 0 pour F1 à F10, si macOS transmet ces touches au navigateur. Le réglage des touches de fonction dans macOS peut modifier leur comportement.

Clique une fois dans l'écran Atari avant de jouer. Plus besoin des boutons virtuels.

Le joystick clavier natif de Hatari utilise les quatre flèches. Maj + flèche permet de saisir une flèche Atari sans déplacer le joystick. Le réglage indépendant des touches nécessite une adaptation du moteur.

Pour tester : démarre un jeu depuis la disquette, puis essaie la croix et FIRE. Clique dans l'écran Atari pour lui donner le focus si nécessaire.
