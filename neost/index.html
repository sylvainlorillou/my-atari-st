Help & shortcuts
  • Mouse: click the middle button (usually the wheel), or press Ctrl+Alt+G, to capture or release it (GEM cursor). Esc and Del are sent to the ST.
  • Keyboard: routed to the IKBD (US layout). Keyboard joystick: arrows + right Ctrl = fire, on the port picked in the Joystick box (port 1 by default).
  • USB pads: detected automatically — first pad on port 1, second on port 0. The dead zone slider only affects analog sticks, not the D-pad.
  • Reset: a cold reset (power-cycle) — ST-RAM is wiped and TOS boots from scratch, which is also what mounting a floppy in A: does.
  • Game floppies: "Mount A: + Reset" switches to a real TOS when one is available (EmuTOS boots system floppies only) — TOS 2.06 on STE/Mega STE, TOS 1.0x on ST. This build bundles EmuTOS alone, which is free software; original Atari TOS ROMs are not ours to ship. Most commercial games therefore need you to add one to /roms and pick it above. The bundled demos boot fine on EmuTOS.
  • Drag and drop: drop a .st / .msa / .dim / .stx image straight onto the screen to mount it in A: and reboot.
  • Machine & RAM: fixed when the machine is built → changing them reloads the page (URL parameters ?machine= and ?mem=, shareable).
  • Sound: browsers require a user gesture — click once inside the screen to unlock audio (YM2149 + STE DMA + drive noises).
